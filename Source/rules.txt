# *********************
# SECTION 1: WILD CARDS
# *********************
# NOTES:
#	1. Wild cards are symbols used in the LEFT and RIGHT of the focus. They are not used in the focus or the output.
#	2. They represent a class of items, such as any punctuation, letter, number, etc.
#	3. List of wild cards symbols:
#  !  = letter
#  #  = digit
#  ~  = blank space, punctuation, decoration, capitalization, range boundary
#     = blank space or capitalization
#  |  = one or more capitalization signs
#  %  = one or more decoration signs (italic, bold, underscore)
#  &  = one or more punctuation signs
#  ;  = one or more letters
#  +  = one or more digits
#  `  = one or more Roman numerals
#  \  = escape wildcard (the wildcard that comes after the escape symbol is read as the literal character and not as a wildcard)
#  glue space = [ ] (copy what is between the brackets)

# ==============================
# <NO-LINE-BREAK-ALLOWED> SYMBOL
# ==============================
# NOTES:
#	1. The <no-line-break-allowed> symbol is used together with <line-break-sequences> in the styles.xml. See https://jwsite.sharepoint.com/sites/whq-wrt-ppd-translation-computer-support/SitePages/software-administration/wts/workspaces/braille-configuration-files/line-break-sequences.aspx
#	2. The <no-line-break-allowed> symbol is used only on the OUTPUT side of a rule.
#	3. Using the symbol will glue together output characters that are normally allowed to break across a line, but need to stay together on the same line in certain circumstances.
#	4. The <no-line-break-allowed> symbol is a vertical bar by default: |
#		Example:
#			1 #[-]#=|-| -
#		The example rule makes numbers that are connected with a hyphen not break across lines.
